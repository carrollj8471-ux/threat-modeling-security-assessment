# Threat Modeling Methodology



## Overview



This project uses a structured threat modeling process to evaluate a fictional cloud-hosted customer portal.



The objective is to identify design-level security risks before deployment and convert those risks into actionable security requirements.



## Process



1. Define the application scenario.

2. Identify important assets.

3. Create a data flow diagram.

4. Identify trust boundaries.

5. Analyze threats using STRIDE.

6. Assign likelihood and impact scores.

7. Calculate risk scores.

8. Map threats to recommended controls.

9. Produce a security assessment report.
